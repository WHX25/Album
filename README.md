# Album - 桌面相册管理应用

一款基于 Qt/C++ 开发的桌面照片相册管理软件，支持项目化管理图片、树形目录浏览、全屏幻灯片播放及背景音乐等功能。采用深色主题界面，交互体验流畅。

---

## 功能特性

- **项目管理**：通过向导创建新的相册项目，支持打开已有项目、关闭/删除项目
- **树形目录组织**：以层级目录树展示项目结构，包含项目节点、文件夹节点和图片节点
- **图片导入**：后台线程递归扫描目录，将图片文件拷贝至项目目录，支持进度条显示和取消操作
- **图片浏览**：双击图片即可查看，通过上一张/下一张按钮在所有图片间顺序导航（基于双向链表实现）
- **全屏幻灯片**：图片间采用交叉淡入淡出动画过渡（约 40fps），支持播放/暂停控制
- **背景音乐**：幻灯片播放时可同步播放 MP3 背景音乐
- **缩略图预览条**：幻灯片模式下底部显示水平滚动的缩略图列表，点击可跳转
- **深色主题**：自定义 QSS 样式表，深灰底色搭配蓝色高亮
- **悬停动画**：导航按钮在鼠标悬停时淡入、移开时淡出

## 界面预览

主窗口分为左右两栏（1:4 比例）：
- **左侧**：项目目录树面板
- **右侧**：图片查看面板

菜单栏提供：
- **文件** → 创建项目（Ctrl+N）、打开项目（Ctrl+O）
- **设置** → 背景音乐（Ctrl+M）

## 构建与运行

### 环境要求

- Qt 6.x（建议 6.2 及以上版本）
- MinGW 64-bit 编译器（或其他 Qt 支持的编译器）
- qmake

### 使用 Qt Creator 构建（推荐）

1. 用 Qt Creator 打开 `Album.pro`
2. 配置构建套件（Kit），选择已安装的 Qt 版本和编译器
3. 点击构建并运行

### 命令行构建

```bash
qmake Album.pro
mingw32-make    # Windows + MinGW
# 或 make       # Linux/macOS
```

构建产物默认位于 `build/` 目录下。

## 使用说明

1. **创建项目**：菜单 → 文件 → 创建项目（Ctrl+N），在向导中输入项目名称和存储路径
2. **导入图片**：在左侧目录树中右键点击项目节点 → 导入文件，选择包含图片的文件夹
3. **浏览图片**：双击目录树中的图片节点，在右侧面板查看；使用左右箭头按钮切换
4. **幻灯片播放**：右键点击项目节点 → 幻灯片，进入全屏播放模式
5. **设置音乐**：菜单 → 设置 → 背景音乐，选择 MP3 文件，幻灯片播放时自动播放

## 核心设计

- **双向链表导航**：所有图片节点通过 `ProTreeItem` 中的前驱/后继指针串联为双向链表，实现跨目录的顺序浏览
- **多线程导入**：图片导入和项目打开均在独立 `QThread` 中执行，避免阻塞 UI，支持进度回调和取消
- **交叉淡入淡出**：`PicAnimationWid` 使用 25ms 定时器驱动 `factor` 从 0 到 1 变化，通过 `QPainter` 的 Alpha 合成实现两张图片间的平滑过渡
- **信号槽联动**：MainWindow 协调目录树与图片面板之间的信号连接，实现选中、导航、清除等操作的同步
